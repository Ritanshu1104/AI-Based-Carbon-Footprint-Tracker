CARBON EVIDENCE LAB — LOCAL START

From the project root in PowerShell:

1. Create an environment if needed:
   python -m venv .venv

2. Activate it:
   .\.venv\Scripts\Activate.ps1

3. Install the small runtime dependency set:
   python -m pip install -r requirements.txt

4. Start the complete application:
   python backend\app.py

5. Open:
   http://127.0.0.1:5000

6. Create a local account in the page to enable encrypted journal history,
   corrections, goals, trends, and forecasts.

OPTIONAL PROVIDERS

Google route evidence:
   $env:GOOGLE_MAPS_API_KEY = "your-key"

Self-hosted OSRM:
   $env:OSRM_BASE_URL = "https://your-osrm-host"

Bill-image OCR:
   Install Tesseract 5 separately and ensure tesseract.exe is in PATH.

Run tests:
   .\.venv\Scripts\python.exe -m unittest discover -s tests -v
